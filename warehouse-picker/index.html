Pick & Sort

1. Add your files

Inventory (optional, remembered on this phone)

A file listing each item number and its bin (like A1), plus the item's name if you have it. Then the orders file only needs the order, item number and quantity: the bins are looked up for you.

Orders

Packing slips (PDF): choose the PDF with all the slips, or select many PDFs at once (one per order is fine). The app reads each slip's order number, items, bins and quantities, and checks them against "Total items".

Or a spreadsheet (Excel or CSV) with one line per item: Order, Box (like A1 = aisle A, box 1), Item (what it is), and optional Details and Qty. Any other columns are shown as details.
